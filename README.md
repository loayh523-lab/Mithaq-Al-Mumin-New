# ميثاق المؤمن

تطبيق إسلامي شيعي باللغة العربية، يُبنى تدريجياً بواجهة RTL وهوية داكنة بالأخضر الزمردي والذهبي.

## الحالة الحالية
- تأسيس مشروع Flutter نظيف.
- واجهة عربية أولية قابلة للتشغيل.
- عدّاد تسبيح تفاعلي.
- إعداد فحص آلي عبر GitHub Actions.

## المتطلبات
- Flutter stable
- Dart المرفق مع Flutter

## التشغيل
```bash
flutter pub get
flutter run
```

> تُضاف النصوص الدينية ومواقيت الصلاة والقبلة بعد ربط مصادر موثوقة واختبار الحسابات على الجهاز.
