# ميثاق المؤمن

تطبيق Flutter عربي باتجاه RTL، بهوية داكنة بالأخضر الزمردي والذهبي، ومكتبة للقرآن الكريم والأدعية والزيارات والعبادات اليومية.

## الحالة الحالية

المشروع قيد التطوير وليس إصداراً إنتاجياً نهائياً. الميزات التالية موجودة في فرع `main`:

- لوحة رئيسية تشمل التاريخ الهجري التقديري، الصلاة القادمة ومواقيت الصلاة، مع الوصول إلى بقية الصفحات من القائمة الجانبية.
- فهرس القرآن الكريم وقارئ النص العثماني دون اتصال بعد إعداد ملف الأصول، والبحث النصي والعلامات المرجعية.
- مكتبة مفاتيح الجنان ومكتبة الأدعية والزيارات مع البحث والمفضلة المحلية.
- تسبيح عام وتسبيح الزهراء عليها السلام.
- سجل الصلاة والقضاء والختمة الشخصية والأعمال اليومية المحفوظة على الجهاز.
- أسماء الله الحسنى، حصن الأذكار، والباحث الذكي.
- مواقيت الصلاة والتقويم الهجري التقديري، وتصحيح يدوي للتاريخ الهجري، واتجاه القبلة باستخدام موقع الجهاز والحساس عند توفره.
- تذكيرات محلية للصلاة قابلة للتخصيص لكل صلاة، وتنبيه اختياري قبل الموعد، ومعاينة تسجيل الأذان المرفق.
- حاسبة يدوية للركعات والسجدات، وتحفظ التقدم محلياً. هي وسيلة تذكّر وليست حكماً على صحة الصلاة.
- أعمال موسمية مرتبطة بالتقويم الهجري التقديري، وصفحة مصادر وخدمات إيمانية، وصفحة «عن التطبيق والدعم» مع المشاركة وروابط المصادر.

## متطلبات التطوير

- Flutter stable وDart المرفق معه.
- اتصال بالإنترنت عند إعداد أصول المحتوى أول مرة، وتشغيل اختبارات GitHub Actions.
- مساحة كافية لبناء Android؛ ملف APK التجريبي كبير لأن النصوص والأصول الصوتية مضمّنة.

## تشغيل المشروع محلياً

```bash
python3 tool/prepare_quran.py
flutter pub get
flutter analyze
flutter test
flutter run
```

قد تحتاج إلى تشغيل سكربتات إعداد المحتوى المشار إليها في `.github/workflows/flutter.yml` إذا كنت تبني خارج GitHub Actions. بناء Actions يجهّز ملفات Android والأصول ثم ينفّذ التحليل والاختبارات ويبني APK للتجربة.

## القرآن الكريم والمصادر

- فهرس السور: `assets/quran/chapters.json`.
- يُجهّز النص العثماني من [dotquran/corpus](https://github.com/dotquran/corpus)، مع التحقق من 114 سورة و6236 آية، ويُنسب النص إلى [Tanzil Project](https://tanzil.net/). راجع شروط المصدر قبل إعادة التوزيع.
- نصوص الأدعية والزيارات تُجهّز من ملفات المصادر في المشروع. ينبغي التحقق من اسم الكتاب والباب والنسبة إلى الرواية عند إضافة أي نص جديد.
- تسجيل الأذان الحالي [AzaanMaahur.ogg على Wikimedia Commons](https://commons.wikimedia.org/wiki/File:AzaanMaahur.ogg)، ويُنسب إلى صاحبه وفق الترخيص المنشور. وصف المصدر لا يثبت مطابقة ألفاظه للأذان الجعفري؛ لذلك لا ينبغي وصفه بأنه تسجيل جعفري موثّق.
- صفحات فقهية وتفسيرية خارجية تتطلب الإنترنت، ولا تُعرض على أنها محتوى مخزن دون اتصال.

## الدقة والحدود المعروفة

- مواقيت الصلاة الحالية تقديرية؛ قارنها بجدول مكتب مرجع تقليدك أو الجهة المحلية التي تعتمدها.
- التاريخ الهجري يستخدم تقويماً حسابياً مع تصحيح يدوي اختياري، وقد يختلف عن ثبوت الهلال محلياً بيوم.
- عمل البوصلة يعتمد على وجود حساس مناسب ومعايرته وعلى دقة GPS. اختبرها على هاتف فعلي.
- إشعارات أندرويد تعتمد على الإذن وإعدادات البطارية، وقد تتأخر على بعض الأجهزة.
- الختمة الشخصية والمفضلة تحفظان محلياً. الختمات الجماعية المتزامنة تحتاج حسابات وخادماً وقاعدة بيانات، وهي ليست مفعّلة.
- التفسير الكامل دون إنترنت، ومكتبة صوتيات مرخّصة للتشغيل بالخلفية، والخلفيات القابلة للتنزيل والتعيين، وتغيير نغمة رنين النظام، واختيار تسجيلات متعددة للأذان تحتاج مراحل تنفيذ واختبار إضافية.
- لم تُجهّز هذه النسخة بعد بمفتاح توقيع إنتاجي أو مسار إصدار Google Play؛ لا تستخدم APK التجريبي كإصدار نهائي للنشر.

## فحوصات CI

GitHub Actions يشغّل `flutter analyze` و`flutter test` و`flutter build apk --debug` ويرفع APK كأثر بناء عند نجاح الخطوات. نجاح الاختبارات الآلية لا يغني عن تجربة GPS والبوصلة والصوت والإشعارات على أجهزة حقيقية.
