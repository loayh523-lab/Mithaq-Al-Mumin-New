# خطة تنفيذ مكتبة ميثاق المؤمن — تغطية شاملة 300+

> الحالة: وثيقة تشغيلية تابعة لوثيقة الأساس والاتفاق التنفيذي الموحد. التقدير 300 مادة أو أكثر بحسب الحاجة، وليس حصة رقمية ملزمة أو سقفاً. هذه الخطة تحدد طريقة البناء والتحقق ولا تعني اكتمال المواد أو الميزات.

## 1. القرار المعتمد

اعتماد الأقسام الستة أدناه لبناء مكتبة شاملة تسد احتياجات المؤمن الشيعي. **300 مادة أو أكثر تقدير تخطيطي مقبول عند الحاجة، وليس عدداً نهائياً مفروضاً**. لا توجد حصص ثابتة لكل قسم؛ يحدد التوزيع بعد جرد النصوص والفجوات، وتُضاف المادة فقط إذا كانت فريدة وكاملة ولها مصدر قابل للتحقق.

| القسم | قاعدة التغطية |
|---|---|
| الورد اليومي والتعقيبات | تغطية الأذكار اليومية وتعقيبات الصلوات وأعمال اليوم |
| الأدعية الكبرى والمناجاة الشريفة | الأدعية المطولة والمناجيات غير المحتسبة في الصحيفة |
| أدعية المناسبات والشهور العبادية | أعمال الشهور والليالي والأيام والمناسبات |
| الصحيفة السجادية المباركة | اختيار المالك المعتمد والمناجيات السجادية دون تكرار |
| أدعية الحوائج والتحصينات والرزق | أبواب الحوائج المتنوعة مع تمييز النص القرآني من الدعاء |
| الزيارات الشريفة والمقامات المقدسة | الزيارات المخصوصة والمطلقة والمشاهد والمقامات |

لا يُملأ العدد بعناوين غير متحققة أو بمتون مكررة. إذا تبين أن مادة غير ثابتة أو ناقصة أو مكررة، لا تُحسب ضمن المنشور مهما كان العدد الناتج.

## 2. تعريف المادة الفريدة

المادة قد تكون دعاءً أو ذكراً أو تعقيباً أو مناجاة أو زيارة أو نص عمل عبادي. لكل مادة:
- سجل واحد ومعرّف ثابت وslug مستقر.
- عنوان معتمد وأسماء بديلة عند الحاجة.
- قسم أساسي واحد، مع وسوم متعددة للوقت أو المناسبة أو الإمام أو الحاجة.
- متن كامل ومقابل على نسخة مصدر محددة.
- إحالة دقيقة إلى الكتاب والباب أو رقم النص، والجزء/الصفحة/الطبعة عند التحقق.
- حالة تدقيق معلنة ومعلومات الحقوق والترخيص عند الحاجة.

إذا ناسب النص أكثر من قسم أو مناسبة، يظهر عبر الوسوم والروابط ولا تُنشأ منه نسخة أخرى. وإذا اختلفت روايتان أو وردت زيادة معتبرة، تسجل الفروق ولا تدمج خفية.

## 3. خريطة أبواب التغطية — دون حصص رقمية

تُستخدم المجالات التالية كقائمة تدقيق للتغطية، لا كأعداد ملزمة أو قائمة عناوين جاهزة:

### 3.1 الورد اليومي والتعقيبات
الأذكار اليومية، الصباح والمساء والاستيقاظ والنوم، تعقيبات الصلوات الخمس، أدعية أيام الأسبوع والجمعة، أذكار الدخول والخروج والطعام والسفر، التسابيح والقنوت وأعمال الصلاة ذات النصوص.

### 3.2 الأدعية الكبرى والمناجاة
الأدعية المطولة، المناجيات المستقلة غير المحتسبة في الصحيفة، أدعية الأئمة والنصوص الخاصة، والأدعية المأثورة الأخرى بعد التثبت. لا تُحتسب مناجيات الصحيفة ضمن هذا القسم.

### 3.3 المناسبات والشهور العبادية
دخول الأشهر وأعمالها، الليالي والأيام الموسمية، الأعياد والمناسبات، والأعمال والأدعية السنوية ذات النصوص والمصادر المحددة.

### 3.4 الصحيفة السجادية المباركة
اختيار المالك السابق من أدعية الصحيفة، والمناجيات السجادية الخمس عشرة بعد مقابلتها على نسخة موثوقة. لا تُخمن معرفات الاختيار ولا تُنشر بقية سجلات المصدر تلقائياً.

### 3.5 الحوائج والتحصينات والرزق
الرزق والدين، الهم والفرج، العافية والمرض، السفر والحفظ، العلم والتوفيق، الأسرة والتوبة وحسن العاقبة. لا تُستخدم ادعاءات آثار مضمونة بلا دليل، ولا يُقدّم الدعاء بديلاً عن العلاج أو المشورة المختصة.

### 3.6 الزيارات الشريفة والمقامات المقدسة
زيارات النبي وفاطمة الزهراء والأئمة عليهم السلام، كربلاء ومراقدها، المشاهد والمقامات المقدسة، الزيارات الأسبوعية والموسمية، والزيارات العامة والجوامع المعتمدة.

يظهر النص في أكثر من باب عند الحاجة عن طريق الوسوم والروابط لا بإنشاء سجل مكرر. ويُحسم حجم كل قسم بعد انتهاء الجرد والمقابلة المصدرية، لا قبل ذلك.

## 4. وظائف المكتبة المعتمدة

1. بحث موحد بالعناوين والأسماء البديلة ومتن النص والإمام والمناسبة والحاجة.
2. تصفح الأقسام الستة بفهرس فرعي ووسوم قابلة للترشيح.
3. قارئ عربي مريح بخط قابل للتكبير وتباعد مناسب وحفظ موضع القراءة.
4. عرض المصدر والإحالة والجزء والصفحة ورقم النص عند التحقق، مع فصل المصدر التراثي عن مستودع البيانات الرقمي.
5. شرح الكلمات الصعبة والملاحظات التحريرية في مساحة مستقلة عن النص الأصلي.
6. المفضلة وآخر ما قُرئ ومتابعة القراءة وسجل القراءة.
7. نسخ ومشاركة النص مع عنوانه ومصدره.
8. عداد اختياري للأذكار التي ثبت عددها وهيئتها في المصدر فقط.
9. صوت اختياري بتسجيلات مرخصة مع نسبة القارئ والمصدر بوضوح.
10. تنزيل المحتوى النصي المعتمد للاستخدام دون اتصال.
11. ربط النص بالمناسبات والأوقات والأئمة والحوائج عبر الوسوم من دون تكرار السجل.
12. حالات تدقيق ظاهرة للفريق التحريري؛ لا يظهر النص غير المحقق كأنه مكتمل.

## 5. قواعد المصادر والتحرير

- الأولوية لمقابلة النص على الكتاب التراثي أو النسخة المحققة، لا الاكتفاء بموقع ناقل.
- يمكن استخدام المستودعات الرقمية كوسيلة وصول وفهرسة، لكنها لا تثبت وحدها نسبة النص أو صحة السند.
- لا يُخمن رقم صفحة أو باب أو نسبة.
- تمييز النص القرآني والحديث والدعاء والزيارة والعمل والشرح.
- عدم تغيير ألفاظ النص المأثور لإصلاح اللغة؛ أي تصحيح أو اختلاف نسخة يوثق بملاحظة منفصلة.
- عدم نشر نص ناقص أو مجهول المصدر لرفع العدد.
- احترام حقوق الطبعات والتحقيقات والتسجيلات الصوتية والتراخيص.
